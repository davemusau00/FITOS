# FITOS Phased Delivery Backlog

## Phase 2: CRM and Leads

Build:
- lead creation
- lead list
- pipeline
- owner assignment
- stage events
- tasks
- conversion
- lost reasons
- source attribution

Exit:
a public/manual lead can become a member without duplicate contact identity.

## Phase 3: Services and Scheduling

Build:
- service types
- trainers
- rooms/resources
- recurring schedules
- materialized occurrences
- occurrence overrides
- trainer/room conflicts
- calendar UI

Exit:
a real studio can publish a weekly timetable.

## Phase 4: Booking

Build:
- staff booking
- public booking
- capacity transaction
- cancellation
- reschedule
- policies
- waitlist
- booking notifications

Exit:
pilot studio can stop using WhatsApp as the authoritative booking register.

## Phase 5: Memberships

Build:
- plan builder
- fixed plans
- session packs
- entitlements
- credit ledger
- expiry
- renew
- cancel

Exit:
booking eligibility and credits are enforced server-side.

## Phase 6: Payments

Build:
- manual cash/bank
- payment intents
- provider abstraction
- M-Pesa
- webhook processing
- matching
- allocation
- receipts
- refunds
- reconciliation

Exit:
daily M-Pesa reconciliation can be performed inside FITOS.

## Phase 7: Attendance

Build:
- reception mode
- member search
- QR/member pass
- class roster
- check-in
- no-show
- overrides

Exit:
paper attendance can be retired.

## Phase 8: Notifications

Build:
- queue
- email
- WhatsApp
- SMS adapter
- booking reminders
- expiry reminders
- receipts
- failure/retry visibility

## Phase 9: Reporting

Build:
- owner overview
- revenue
- active memberships
- attendance
- occupancy
- lead funnel
- exports

Exit:
owner can answer core operational questions without spreadsheets.

## Phase 10: Tenant Website

Build:
- branded public profile
- services
- trainers
- timetable
- memberships
- integrated booking
- SEO/public metadata
- custom domains later

## Phase 11: Advanced Operations

- commissions
- POS
- inventory
- corporate plans
- multi-branch depth
- access-control hardware
- freeze/upgrade/downgrade
- family/group plans

## Phase 12: Intelligence

Only after data quality is trustworthy:
- churn indicators
- capacity recommendations
- underperforming class signals
- lead follow-up suggestions
- operational natural-language assistant

AI must not autonomously alter financial or membership truth.
